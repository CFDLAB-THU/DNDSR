1-D Stoichiometric Premixed H2/Air Flame Workspace
===================================================

Cantera reference: Su = 2.2540 m/s (h2o2.yaml, mixture-averaged, no Soret,
matching DNDSR transport).  Generated by
`scripts/reaction/h2o2_free_flame_mixture_averaged.py`.
Burned T = 2360.02 K, T_u = 300 K, p = 101325 Pa.

Strategy
--------

Front tracked by midpoint-temperature crossing (T_mid ≈ 1330 K).
Marker speed from sliding 5-pt linear fit (t_code < 0.6, later half
of eligible windows, R² > 0.99998).  Then:

    Su = marker_speed − u_unburned(ahead of flame)

Tools
-----

* `analyze_flame_speed.py` — flame speed analysis and marker plotting
* `plot_output_digest.py` — profile/history digest from a DNDSR output dir
